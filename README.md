<h2 id="sobre-o-projeto">📌 Sobre o Projeto</h2>

O **Park Tech Frontend** é a interface da aplicação Park Tech, responsável por consumir a API do backend e apresentar as informações de forma clara, rápida e intuitiva para o usuário final.

O projeto foi desenvolvido com foco em:

- **Consumo eficiente da API** do backend
- **Componentização e reuso de código** com React
- **Tipagem forte e segurança** com TypeScript
- **Performance e carregamento rápido**
- **Interface consistente e acessível** com shadcn/ui
- **Experiência fluida em desktop e mobile**

A estrutura prioriza clareza das informações, organização dos componentes e integração direta com o [backend do Park Tech](https://backend-eight-inky-80.vercel.app).

<h2 id="modo-de-uso">▶️ Modo de Uso</h2>

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/parktech-frontend.git
```

2. Acesse a pasta do projeto:

```bash
cd parktech-frontend
```

3. Instale as dependências:

```bash
npm i
```

4. Crie um arquivo `.env` na raiz do projeto apontando para a API do backend, por exemplo:

```env
VITE_API_URL="https://backend-eight-inky-80.vercel.app"
```

5. Rode o projeto em ambiente de desenvolvimento:

```bash
npm run dev
```

6. Acesse no navegador o endereço exibido no terminal (geralmente `http://localhost:5173`).

> ⚠️ Para o funcionamento completo da aplicação, é necessário que a [API do backend](https://backend-eight-inky-80.vercel.app) esteja em execução (local ou em produção).
